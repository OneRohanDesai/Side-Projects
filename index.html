Who I am

I'm a DevOps and infrastructure person. Most of my time goes into clusters, pipelines, cloud accounts, and monitoring — local Kind/k3s boxes as much as managed ones like EKS. I like knowing what a system is doing, not guessing from a dashboard screenshot.

I'm not trying to sound like a product. I break things on purpose when I'm learning, write things down when I figure them out, and keep a pile of side projects that range from serious practice labs to small tools I needed for myself.

03

What I actually do

  • Stand up and tear down platforms so I can practice for real - not just read docs
  • Wire metrics, logs, and traces so problems are visible instead of mysterious
  • Write Terraform and Ansible so the next run looks like the last one
  • Use GitOps and CI when it saves me from clicking the same thing twice
  • Build small apps when a problem in real life needs a tool, not a slide deck
  • Things fail. I want to see how, not pretend they won't.
  • Simple setups I can explain beat clever ones I can't debug at 2 AM.
  • I write notes and runbooks mostly because I forget details later.
  • Running it on my laptop first usually teaches more than a long design doc.
  • Not every project has to be finished or public. Some stay messy on purpose.
