# Isengard

**Saruman's playbook** — published, practical playbooks for DevOps, SRE, cloud, and infrastructure operations.

Open the deployed site at `/isengard/`. All website files live in this directory. Cloudflare setup files are in [`cloudflare/`](cloudflare/README.md); follow that guide after your GitHub deployment publishes this folder.

Features: searchable playbook library, Markdown runbooks, a private CRUD console, anonymous like/dislike/report actions, share links, D1 storage, and KV-backed cache invalidation.
