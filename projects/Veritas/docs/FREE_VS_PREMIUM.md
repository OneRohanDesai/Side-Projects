# Free vs Pro vs Enterprise

Entitlements are **structured**, not a single `if premium` flag.

| Capability | Free | Pro | Enterprise |
| --- | --- | --- | --- |
| Time limit | unlimited | unlimited | unlimited |
| Max nodes | 3 | 50 | custom / unlimited |
| Max agents | 3 | 50 | custom |
| Max seats | 1 | 10 | custom |
| Retention | 3 days | 30 days | custom |
| What Changed | basic (single window) | full windows + chains | + custom packs |
| Why Engine | limited confidence UI | full RCA | full + export |
| Forecast | 2 resources | full capacity suite | + custom models |
| Archaeology | 7 days | 90 days | custom |
| Cost intelligence | demo only | full | multi-cloud |
| Security context | basic | advanced | + integrations |
| Autonomous reports | daily only | daily+weekly+capacity | full suite + postmortem |
| Local AI | optional basic | advanced prompts | private endpoint / air-gap packs |
| Cloud AI | — | optional | optional / private |
| Plugins | core set | extended | custom + signed private |
| Offline license | — | — | yes |
| SSO / LDAP / OIDC | — | — | yes |
| RBAC + audit | — | basic roles | full |
| HA / fleet | — | — | yes |
| Support | community | standard | premium |

## Product rule
**Never break local offline operation** to upsell cloud. Cloud is optional acceleration, not the product.
