# UI Modules

## Aesthetic · Rose Petal

```css
--color-1: #FE4365;
--color-2: #FC9D9A;
--color-3: #F9CDAD;
--color-4: #C8C8A9;
--color-5: #83AF9B;
```

Rules:
- Zero border radius. Sharp corners only.
- No hyphen characters in chrome copy. Prefer spaces or middle dots.
- Page titles only. No subtitle paragraphs under titles.
- Help `?` opens a focused modal with topic content.
- Dense, calm, powerful. Not noisy.
